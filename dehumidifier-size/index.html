    How it works: sizes come from ENERGY STAR's recommended capacity ranges (as of 2026). Under 500 sq ft the tool uses the low end of the range; from 500 to 2,000 sq ft it uses the high end, because basements run cool and cool air cuts what any unit really removes; over 2,000 sq ft it scales up with area. Ceilings over 8 ft add proportionally. Then it picks the next common size: 22, 35 or 50 pints. Today's labels use the DOE's 2019 test, so an older "70-pint" unit is about a 50 on today's scale.
