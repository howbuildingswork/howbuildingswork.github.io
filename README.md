# How Buildings Work: free tools

Free one-question calculators that go with episodes of the How Buildings Work YouTube channel.
Live at https://howbuildingswork.github.io/

| Path | Tool | Episode |
|---|---|---|
| `/attic-insulation/` | How much attic insulation do I need? | Ep4, ice dams |
| `/windows-sweating/` | Why are my windows sweating? | Ep6, window condensation |

Each tool is one self-contained `index.html` in its own folder. Settings (Amazon tag, episode link) sit at the top of each tool's script.
