# How Buildings Work: free tools

Free one-question calculators that go with episodes of the How Buildings Work YouTube channel.
Live at https://howbuildingswork.github.io/

| Path | Tool | Episode |
|---|---|---|
| `/attic-insulation/` | How much attic insulation do I need? | Ep4, ice dams |
| `/frozen-pipes/` | Will my pipes freeze? | Ep5, frozen pipes |
| `/windows-sweating/` | Why are my windows sweating? | Ep6, window condensation |
| `/dehumidifier-size/` | What size dehumidifier do I need? | Ep7, musty basement |
| `/privacy/` | Privacy & disclosures (cookies, not professional advice) | All pages link it from the footer |

Each tool is one self-contained `index.html` in its own folder. Settings (episode link) sit at the top of each tool's script.
